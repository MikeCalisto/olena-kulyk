# Сайт Olena Art — правила роботи

## Сайт

Репозиторий: `github.com/MikeCalisto/olena-kulyk` → Vercel-проект `olena-kulyk`
→ https://olena-kulyk.vercel.app. Корень `/` редиректит на `/morskyi-peyzazh/`.

```
site/
  morskyi-peyzazh/        мини-курс №1 — ПРОД, источник правды
  morskyi-peyzazh-v2/     сборка с предметными сценами, noindex
  patch_v2.py             собирает v2 из прода
  copy_edits.py           правки текста от Олены
  objects.css             CSS предметных сцен
  pixel.py / pixel.js     Meta Pixel
  промты/                 промты для генерации картинок (не деплоятся)
```

### Главное правило

**`morskyi-peyzazh-v2/` не редактируется руками.** Он целиком пересобирается из
прода каждым запуском `patch_v2.py`. Любая ручная правка там исчезнет при
следующей сборке.

- правишь **вёрстку и разметку** → в `morskyi-peyzazh/index.html`
- правишь **текст от Олены** → пара `(было, стало)` в `copy_edits.py`
- правишь **сцены с предметами** → `patch_v2.py` и `objects.css`

Потом всегда:

```bash
cd site && python3 patch_v2.py
```

`copy_edits.py` роняет сборку, если фрагмент не нашёлся или нашёлся дважды. Это
не баг, а страховка: правка не может тихо не примениться.

### Деплой

```bash
cd site && npx vercel --prod --yes
```

После деплоя **проверяй с cache-buster**, иначе поймаешь CDN-кэш и решишь, что
деплой не прошёл:

```bash
curl -s "https://olena-kulyk.vercel.app/morskyi-peyzazh/?cb=$RANDOM" | grep -c zenedu
```

Пуш в `main` тоже запускает продовый деплой. Держи репозиторий и прод в одном
состоянии: всё, что залито через CLI, должно быть закоммичено, иначе следующий
чужой пуш откатит сайт к репозиторию.

## Как добавить страницу нового мини-курса

1. `cp -r site/morskyi-peyzazh site/<slug>` — slug латиницей, как `morskyi-peyzazh`.
2. Внутри поправь пути ассетов: в проде они относительные (`assets/…`),
   так что копия сразу работает автономно со своей папкой `assets/`.
3. Замени тексты, картинки, ссылку оплаты, `<title>` и `<meta name="description">`.
4. `cd site && python3 patch_v2.py` — впишет Meta Pixel в новую страницу
   автоматически. Он ищет `<meta charset>`, иначе `<head>`; если не нашёл ни
   того, ни другого, печатает `БЕЗ ПІКСЕЛЯ` и имя файла.
5. Проверь локально, задеплой, закоммить, запушь.

Когда курсов станет больше одного — решить, куда ведёт `/`. Сейчас в
`site/vercel.json` жёсткий редирект на `/morskyi-peyzazh/`.

Юридические страницы (`oferta.html`, `politika.html`) у каждого курса свои и
называют адрес сайта внутри текста — при копировании проверь, что там правильный
домен и правильный путь.

## Meta Pixel

ID `1643966413961899` живёт в одном месте — константа `PIXEL_ID` в `site/pixel.py`.
Оттуда он попадает и в `/pixel.js`, и в `noscript`-картинку. Меняешь константу →
`python3 patch_v2.py` → обновятся все страницы разом.

`pixel.js` грузится с `async`. Свои события (`fbq('track', …)`) пиши внутри
`pixel.js`, а не отдельным инлайн-скриптом на странице — тот может выполниться
раньше, чем определится `fbq`.

## Грабли, на которые уже наступали

- **`img{max-width:100%}` молча сплющивает предметы.** Всегда задавай `width` +
  `max-width:none` + `height:auto`, иначе объект рендерится с ломаными пропорциями.
- **Не задавай высоту сцены через `padding-bottom:%`, если ширина объекта в `%`.**
  Процентный padding считается от ширины секции, процентная ширина — от ширины
  элемента. На узких экранах базы расходятся и объект обрезает.
- **Перекрытия — в `%`, не в `px`.** Фиксированный `margin-top:-40px` верен на 480
  и неверен на 375.
- **Контраст меряй по отрендеренному PNG, а не на глаз.** Цель ≥4.5:1 для текста.
- **В шрифте Jost нет украинских «І», «і», «ї».** На сайте браузер подставляет
  системный шрифт незаметно. В растровых картинках (обложки Telegram) их надо
  подменять латинскими `I`, `i`, `ï`.
- **Скрытая Browser-панель усыпляет видео** (`document.hidden: true`). Проверяй
  автоплей через DOM, а не по скриншоту панели.
- **`preview_start` не поднимет сервер из ~/Desktop** — процесс туда не пущен.
  Сервер стартуют вручную из терминала, конфиг в `.claude/launch.json` только
  подключается к нему.
- **`.vercel/project.json` должен содержать актуальное имя проекта.** Когда оно
  разошлось с Vercel, CLI отвечал `Not authorized` — сообщение врёт, дело в имени.
- **На аккаунте Higgsfield 0 кредитов и бесплатный план** — картинки генерировать
  нечем. Промты пишем в `site/промты/`, генерирует их Михаил в ChatGPT.

## Тон и содержание

Сайт написан **от первого лица Олены**. Любой новый текст — тоже. Тексты правит
Олена, приходят скриншотами из Telegram; внедряем дословно, а очевидные опечатки
(русская «и» вместо «і», дефисы, запятые) чиним молча и сообщаем об этом.

Не обещай на странице того, чего нет. Формулировку «телефон и стол, больше ничего
не нужно» пришлось убрать именно поэтому: материалы всё-таки нужны.
