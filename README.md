# olena-kulyk

Лендинг міні-курсу **«Швидкий морський пейзаж»** — Олена Кулик Діріл.

- Продакшн: https://olena-kulyk.vercel.app/morskyi-peyzazh/
- Корінь `/` редіректить на `/morskyi-peyzazh/`

## Структура

```
morskyi-peyzazh/            прод
  index.html                лендинг (17 блоків)
  politika.html             політика конфіденційності
  oferta.html               публічна оферта
  assets/                   фото, відео уроків, предмети, мазки (webp з альфою)
morskyi-peyzazh-v2/         збірка з предметними сценами, noindex
patch_v2.py                 збирає v2 з проду
copy_edits.py               правки тексту від Олени, накладаються під час збірки
objects.css                 CSS сцен, вшивається в v2
vercel.json                 редірект з / та річний кеш на assets
```

`.vercelignore` тримає скрипти збірки поза деплоєм — на прод їде лише статика.

## Кнопки оплати

Усі шість CTA (п'ять `.cta` у тексті + кнопка в липкій панелі `.sb`) ведуть на
https://app.zenedu.io/l/b0UHs946nQoZjzCj. Це `<a>`, а не `<button>` — тому
`a.cta` і `.sb a` мають власні `text-decoration:none` та `box-sizing`.

## v2 — предметні сцени

`morskyi-peyzazh-v2/` — повна копія проду з `noindex`. Ассети й далі беруться з
`/morskyi-peyzazh/assets/`, дублікатів немає. Копія збирається скриптом заново з
`morskyi-peyzazh/index.html`, тож правки на проді підхоплюються автоматично.

| Блок | Предмет | Як розміщений |
|---|---|---|
| 1 · Перший екран | мазок + хвиля з фарби | задній план, `hero-obj` |
| 3 · Чому саме ця картина | кисті | поруч із текстом, фон `#103F52` |
| 4 · Олія простіша за акварель | тюбики з мазком | поруч із текстом, фон `#EAE2D2` |
| 7 · Матеріали | палітра з пензлем | смуга під заголовком, фон `#134B5E` |
| 8 · Програма | інструменти | задній план під діагональною маскою |
| 15 · Фінальний офер | мольберт | задній план під діагональною маскою |

Блоки 3 і 4 йдуть підряд, тому 4-й зроблений світлою сценою — інакше два темні
екрани поспіль. Роздільник між ними перефарбований у колір піску (`.obj-div`).

У блоці 1 заголовок іде поверх мазка, тому в `.h1-script` доданий білий ореол —
без нього слово «першу» зливалося з фарбою.

### Предмети

`assets/obj-*.webp`, `hero-*.webp` — згенеровані в ChatGPT, вирізані скриптом
(альфа з чисткою облямівки; де фон прийшов суцільним — заливка від краю), 89–190 КБ.
У кистей знизу градієнт прозорості, бо ручки обрізані краєм кадру.

Висоту сцени задає сама картинка в потоці, а не `padding-bottom` у відсотках:
відсотковий `padding` рахується від ширини секції, відсоткова `width` — від ширини
елемента, і на вузьких екранах ці дві бази розходяться, предмет обрізало.

Предмет на задньому плані завжди під діагональною `mask-image` — вона гасить його
рівно там, де лежить текст. Картки поверх предмета — матове скло
(`rgba(...,.62)` + `backdrop-filter`), контраст міряється по відрендереному PNG.

Плашки-іконки — інлайн-SVG спрайт (11 гліфів) одразу після `<div class="phone">`.
Вони належать тільки сценам «предмет поруч із текстом»; на задньому плані їх немає.

### Перезбирання

```bash
python3 patch_v2.py   # копіює прод у v2 і накладає сцени; ідемпотентний
```

Скрипт падає, якщо якийсь фрагмент тексту з `copy_edits.py` не знайшовся або
знайшовся двічі — це страховка від того, що правка тихо не застосується.

## Дизайн

Мобільний стовпчик 480px · Jost + Marck Script · базовий кегль 17px.
Чорнило `#0C2E47`, море `#1E7C96`, аква `#66C2BF`, корал `#E0653C`.

Мазки `assets/stroke-*.webp` згенеровані з макрознімків справжнього полотна Олени —
альфа-маска будується зі структури щетини (34–52 ворсини, суха кисть до хвоста, рвані кінці).

У Jost немає українських «І», «і», «ї» — на сайті браузер підставляє системний
шрифт непомітно, але в растрових обкладинках для Telegram їх доводиться
підміняти латинськими.
